# Garagem 26 — aplicativo

Aplicativo nativo Android/iOS baseado no sistema atual da Garagem 26.

- App ID: br.com.nikkeilogistica.garagem26
- Android: APK de teste pode ser gerado pelo GitHub Actions.
- iPhone: o projeto iOS pode ser aberto no Xcode e instalado no aparelho.
- Os dados continuam no mesmo Supabase e a interface é carregada da versão oficial da Garagem 26.
